## Tipe data string

- String ada tipe data kumpulan karakter
- Jumlah karakter di dalam string bisa nol sampai tak terhingga
- Tipe data string di Golang di representasikan dengan kata kunci string
- Nilai data string di Golang selalu diawali dan diakhiri dengan karakter petik dua (")

## Function untuk String

| Function | Keterangan |
| --- | --- |
| `len("string")` | Menghitung jumlah byte di dalam string |
| `"string"[number]` | Mengambil byte pada posisi (indeks) yang ditentukan |
